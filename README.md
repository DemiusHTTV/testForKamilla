## Маленькое напоминалка 

| Тип        | Когда использовать                                   |
|------------|------------------------------------------------------|
| `feat`     | добавил что-то новое                                 | 
| `fix`      | исправил ошибку                                      |
| `docs`     | изменил документацию, README                         | 
| `style`    | форматирование, пробелы, отступы (логика не меняется)| 
| `refactor` | переписал код без изменения поведения                | 
| `test`     | добавил или поправил тесты                           |
| `chore`    | служебное: .gitignore, настройки, зависимости        |

`feat: added constructore`

*** Задание 2. Своя ветка ***
1. Создай ветку `feature/about-me` и переключись на неё.
2. Создай файл `about-me.md` и напиши пару строк о себе.
3. Сделай **минимум два** коммита (например, сначала создал файл, потом дописал).

5. Открой Pull Request из `feature/about-me` в `main` **своего форка** и смержи его через интерфейс GitHub.
6. Подтяни изменения локально (`git pull`)
